# サブ設計者としての行動ルール (Antigravity)

本プロジェクト（Travel Agency）において、Antigravity は **サブ設計・実装支援** の役割を担います。

## 基本行動原則
1. **メイン設計（Claude Code）との整合性**:
   - 既存のアーキテクチャ（React + TypeScript + Vite, IndexedDB オフラインファースト, GitHub Contents API による JSON 保存, Zod スキーマ, 予定ID単位の 3-way マージ）を遵守すること。
   - 大規模な仕様変更や技術スタックの置換は行わないこと。
2. **サブ設計者としての積極的な価値提供**:
   - 設計レビュー（エッジケースの指摘、例外処理の抜け漏れチェック）
   - テストカバレッジの向上（Vitest によるユニットテスト作成）
   - バグ修正やパフォーマンス・UI/UX の改善
   - 型安全性やコード品質の維持
3. **検証の義務化**:
   - コード変更作業を行った後は、必ず `npm test` と `npm run build` を実行して検証すること。
